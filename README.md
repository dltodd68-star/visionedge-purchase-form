# VisionEdge AI Media - Purchase Form

A complete purchase form system with Stripe integration for selling AI business products with setup fees and monthly subscriptions.

## ✨ Features

- 💳 **Stripe Integration** - Secure payment processing
- 📧 **Email Notifications** - Automatic emails to customer, salesperson, and owner
- 📱 **Mobile Responsive** - Beautiful design on all devices
- 🔄 **Recurring Billing** - Setup fee + monthly subscription
- 🎨 **Professional UI** - Modern gradient design with VisionEdge AI Media branding

## 🚀 Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/YOUR_USERNAME/visionedge-purchase-form)

### Environment Variables Required:

```
STRIPE_SECRET_KEY=your_stripe_secret_key
STRIPE_WEBHOOK_SECRET=your_webhook_secret
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your_email@gmail.com
SMTP_PASS=your_gmail_app_password
SMTP_FROM=your_email@gmail.com
BASE_URL=https://your-vercel-url.vercel.app
```
